SVG stack preview

Some examples of source code are available under each widget.

Conventional CSS sprite (preferred):
This technique uses CSS classes to display portions of the sprite as background image of appropriately sized elements.
Image HTML tag

SVG images make use of fragment identifiers (IDs) to reference certain portions of the external sprite. By default, CSS hides all shapes inside the sprite. The `:target` pseudo selector is used to show the very shape referenced by the fragment identifier.

This preview features an SVG stack. Please be aware of the following:

  • Your browser has to support SVG fragment identifiers for SVG stacks to work.
  • Support for SVG fragment identifiers hasn't always been that decent. For older browsers you will have to use some polyfill like fixsvgstack.jquery.js.

    Used when the icon is not purely decorative and conveys essential information.

  <i class="stack-icon stack-icon-account" aria-hidden="true"></i>

</a>
