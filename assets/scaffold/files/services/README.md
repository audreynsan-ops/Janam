# Services folder

This folder contains scaffolded service configuration files used by the project.

## Purpose

The files in this folder are generated as part of the project scaffold and are
intended to provide a default, working service setup.

## Custom project configuration

If a project needs a specific service configuration, you may modify the
scaffolded files in this folder to match those requirements.

Because these files are scaffolded and may be tracked by Git ignore rules, any
file you intentionally modify and want to commit should be added with force:

```shell
git add -f services/<file-name>
```

## Notes

- Keep the default scaffolded files unless the project requires a specific 
  configuration.
- Use forced Git add only for files that are meant to be versioned.
- Review changes carefully before committing, since service files can affect 
  local and deployment environments.
